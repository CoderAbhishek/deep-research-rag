# Deep Research RAG Engineering

A production-grade Retrieval-Augmented Generation (RAG) system designed for
multi-document research and consulting intelligence.

## What this project demonstrates

- Multi-document corpus management with rich metadata
- Advanced chunking strategies (recursive, parent-child)
- Hybrid retrieval: dense vector search + BM25 sparse retrieval
- Reciprocal Rank Fusion for combining ranked lists
- Query engineering: rewriting, multi-query, HyDE
- Cross-encoder reranking
- Systematic evaluation: retrieval metrics (Recall@k, MRR) and answer metrics
- FastAPI application layer
- Docker containerisation

## Domain

Market research and consulting documents — annual reports, industry reports,
DRHPs, expert transcripts.
